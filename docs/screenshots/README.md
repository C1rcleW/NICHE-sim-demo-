# 截图目录

README 的「Web 仪表板」章节会引用本目录下的图片。请放入以下文件：

| 文件名 | 内容 | 用途 |
|---|---|---|
| `dashboard.png` | 仪表板总览（Charts 标签页，含时间序列与生境散点图） | README 主截图 |
| `fitting.png` | Fitting 标签页（拟合结果与告警） | 可选，用于说明拟合页 |
| `network.png` | Network 标签页（家庭关系网络图，需 `networkx`） | 可选 |

放入后，把 `README.md` 中对应 `![...]` 行的注释去掉即可显示。

## 截图建议

- 分辨率不低于 1600×900，浏览器窗口最大化后截图
- 使用默认配置（2 个家庭 5 名成员，120 步）以便与文档中的基线一致
- 中英文各截一张也可，便于说明双语支持

## 为什么不用外链

GitHub 附件链接（`github.com/user-attachments/...`）的有效性无法在仓库内验证，
一旦失效 README 就会出现破图。改为本地路径后，图片随仓库一起版本化。
